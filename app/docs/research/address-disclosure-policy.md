# Google Play 개발자 주소 공개 정책 (2차 검증 포함)

## 문서 정보

- 리서치 도구: `agy` CLI (`gemini-3.1-pro-high`), 2회에 걸쳐 조사 (1차 일반 조사 → 2차 실제 스토어 페이지 조회로 검증)
- 작성일: 2026-08-06 (Phase 1)
- **주의**: 2차 검증에서도 웹 조회 기반 추정이 섞여 있다. 실제 Play Console 가입/스토어 설정 화면에서 최종 확인 필요.

## 결론 (검증 완료)

**개인(Individual) 계정 + 인앱결제 없음(AdMob 광고만) + Play Console 스토어 설정의 주소란을 비워두는 조건**이면 실거주지 주소는 스토어에 공개되지 않는다.

- AdMob 광고 수익은 Play Console의 유료 판매자(Merchant/Payments Profile)를 생성하지 않으므로 주소 공개 의무를 유발하지 않는다.
- 실제 국내 개인 개발자 앱들에서 주소가 노출된 사례는 Google의 강제가 아니라 **개발자가 Play Console `스토어 설정 > 개발자 연락처`에 주소를 직접 입력**했거나 계정을 조직(Organization)으로 등록했기 때문이다.
- 주소 공개가 실제로 강제되는 경우: 유료 앱/인앱결제 판매(Merchant 계정 생성), 조직 계정, EU DSA 상인(Trader) 선언, 또는 스토어 설정에 수동 입력.

## 1차 조사 결과 (일반 정책 조사)

- 2023년 개발자 검증 정책 개편: 개인 계정도 정부 신분증 + 주소 증빙 서류로 신원 검증 필요 (Google 내부 제출용, 스토어 공개와는 별개)
- 조직 계정은 D-U-N-S 번호 필요
- P.O. Box/가상오피스는 개인 계정 검증 시 불허 (실거주지 증빙 요구)
- 가상오피스로 주소를 대체하려면 사업자등록 후 조직 계정 전환이 사실상 유일한 합법적 경로로 조사됨 → 현재 사용자는 사업자등록이 어려운 상황이라 이 경로는 배제

## 2차 검증 결과 (실제 스토어 페이지 조회)

| 대상 | 확인 결과 |
|---|---|
| Vivino (`vivino.web.app`) | 회사 주소 공개됨 (덴마크 코펜하겐 사무실 주소) — 유료 판매/IAP로 Merchant 계정 보유, 조직 계정 성격 |
| 국내 개인 개발자 앱 3종 (NowClip, 한방에 메모장, 태그노트) | 실거주지 주소(아파트 동·호수 포함) 노출 확인 — 원인은 스토어 설정에 직접 입력 |
| Google 공식 정책 (support.google.com/googleplay/android-developer/answer/10840893 인용) | "개인 계정으로 앱을 게시하면 이메일 주소와 국가만 표시된다. 유료 판매/IAP(Merchant 계정), 조직 계정, EU DSA 상인 선언, 또는 스토어 설정에 수동 입력한 경우에만 전체 주소가 공개된다" |

## DrinkDiary 적용 방침

1. Google Play Console 가입 시 **개인(Individual) 계정** 유지
2. **인앱결제(IAP)를 도입하지 않음** — 수익화는 AdMob 광고만 사용 (기존 Phase 2 계획과 일치)
3. **스토어 설정(Store settings) > 개발자 연락처의 주소 입력란을 공란으로 유지** — 이메일(`greatescape8274@gmail.com`)만 입력
4. 개발자 표시명은 `spicyrabbit`으로 등록
5. 실제 등록 화면에서 주소 입력이 필수 항목으로 강제되는지 여부는 Phase 4(릴리즈 준비)의 Play Console 계정 개설 시점에 최종 확인
