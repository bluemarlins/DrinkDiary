# 주종별 테이스팅 보카블러리 명세 (와인 / 위스키 / 맥주)

## 문서 정보
* **리서치 도구**: agy/gemini-3.5-flash-medium
* **작성일**: 2026-08-08
* **주의사항 (Caveat)**: 본 문서는 AI 리서치를 통해 작성된 tasting vocabulary 명세로, UI 텍스트로 최종 반영하기 전에 반드시 기획 및 사용자 리뷰(또는 전문가 검수)를 거쳐야 합니다.

---

## 1. 개요 및 설계 방향
DrinkDiary 앱의 기존 느리고 복잡한 숫자 입력식 평점 UI를 대체하여, 직관적이고 빠른 **SNS 스타일의 선택형 태그 칩(Chip) UI**를 도입합니다.
* **칩 레이블 제약**: 모바일 화면 크기를 고려하여 한국어 기준 **2~5글자**를 권장하며, 절대 최대 **8글자** 이하로 제한합니다.
* **난이도 구분**:
  * **입문 (casual)**: 일반 대중이나 초급자가 직관적으로 이해하고 쉽게 사용할 수 있는 어휘.
  * **전문 (enthusiast/pro)**: 애호가나 전문가들이 주로 사용하는 구체적이고 학술적인 어휘.
* **주종별 구성**: 각 주종의 대표적인 평가 기준(와인 WSET SAT, 위스키 Nosing & Palate 기법, 맥주 BJCP/Flavor Wheel)을 근간으로 하되, 국내 소비자들이 일상적으로 쓰는 한국어 표현을 최우선으로 선정했습니다.

---

## 2. 와인 (와인) 테이스팅 칩 명세

와인은 포도 품종과 오크 숙성, 병 숙성에서 오는 다채로운 풍미를 표현할 수 있도록 **향, 맛, 바디/질감, 여운** 4가지 카테고리로 분류합니다. (WSET SAT 표준 기반)

### [카테고리 1] 향 (Aroma)
와인을 마시기 전 코로 느끼거나 머금었을 때 비강으로 올라오는 향을 표현합니다.

| 한국어 레이블 | 난이도 | 1줄 설명 (의미) |
| :--- | :---: | :--- |
| **시트러스** | 입문 | 레몬, 라임, 자몽, 오렌지 등의 상큼하고 톡 쏘는 감귤류 향 |
| **붉은 과일** | 입문 | 딸기, 체리, 라즈베리, 크랜베리 등 밝고 상큼한 과일 향 |
| **검은 과일** | 입문 | 자두, 블랙베리, 블루베리 등 짙고 달콤하며 묵직한 베리 향 |
| **열대 과일** | 입문 | 파인애플, 망고, 패션프루트, 바나나 등 이국적이고 달콤한 향 |
| **핵과류** | 전문 | 복숭아, 살구, 자두 등 부드러운 과육과 단단한 씨가 있는 과일 향 |
| **말린 과일** | 전문 | 건포도, 말린 무화과, 푸룬(건자두) 등 진하게 농축된 과일 향 |
| **꽃향기** | 입문 | 장미, 아카시아, 제비꽃, 인동덩굴 등 화사하고 향긋한 꽃내음 |
| **풀/허브** | 입문 | 갓 깎은 잔디, 민트, 피망, 유칼립투스 등 싱그러운 식물성 향 |
| **오크** | 입문 | 참나무 숙성통에서 배어 나온 그윽한 나무 향과 구운 토스트 향 |
| **바닐라** | 입문 | 새 오크통 숙성에서 우러나는 달콤하고 부드러운 버터리한 향 |
| **가죽/흙** | 전문 | 잘 숙성된 올드 빈티지 와인에서 나는 젖은 흙, 낙엽, 가죽 향 |
| **빵/효모** | 전문 | 스파클링 와인 등의 효모 접촉에서 오는 갓 구운 빵과 이스트 향 |

### [카테고리 2] 맛 (Taste)
입안에서 느껴지는 맛의 미각적 특성을 표현합니다.

| 한국어 레이블 | 난이도 | 1줄 설명 (의미) |
| :--- | :---: | :--- |
| **드라이** | 입문 | 당분이 거의 남아있지 않아 단맛 없이 깔끔하게 떨어지는 맛 |
| **은은한 단맛** | 입문 | 끈적이지 않고 혀끝에 기분 좋게 감도는 은근한 달콤함 |
| **달달함** | 입문 | 디저트 와인이나 포트 와인처럼 직접적이고 확실하게 단맛 |
| **새콤함** | 입문 | 신선하게 침샘을 자극하여 침이 고이게 만드는 기분 좋은 신맛 |
| **시큼함** | 전문 | 산도가 매우 강조되어 톡 쏘듯 강렬하게 느껴지는 개운한 신맛 |
| **짭조름함** | 전문 | 해안가 테루아나 석회질 토양에서 기인한 미네랄 특유의 감칠맛 |
| **스파이시** | 전문 | 후추, 계피, 정향 등 알싸하게 혀를 자극하는 향신료의 느낌 |
| **쌉싸름함** | 입문 | 탄닌이나 쌉쌀한 줄기 풍미에서 우러나는 기분 좋은 씁쓸함 |
| **잘 익은 과일** | 입문 | 풋내 없이 과즙이 가득 차올라 자연스러운 과일 풍미가 넘치는 맛 |
| **복합적인 맛** | 전문 | 단맛, 신맛, 과일 풍미 등이 한데 뭉치지 않고 다채롭게 표현되는 맛 |

### [카테고리 3] 바디/질감 (Body & Texture)
와인의 무게감과 입안에서 닿는 물리적인 촉감을 표현합니다.

| 한국어 레이블 | 난이도 | 1줄 설명 (의미) |
| :--- | :---: | :--- |
| **가벼움** | 입문 | 물이나 가벼운 주스처럼 입안에서 경쾌하고 가뿐하게 흐르는 느낌 |
| **묵직함** | 입문 | 우유나 농축 주스처럼 입안을 가득 채우며 꽉 찬 무게감이 드는 바디 |
| **부드러움** | 입문 | 까끌거리거나 거슬리는 느낌 없이 부드럽고 유연하게 목을 타는 촉감 |
| **떫은맛** | 입문 | 포도 껍질의 탄닌 성분 때문에 혀와 입천장이 꽉 조이고 마르는 느낌 |
| **매끄러움** | 전문 | 실크나 벨벳처럼 입자감이 아주 곱고 우아하게 입안을 감싸는 질감 |
| **유질감** | 전문 | 화이트 와인 등에서 버터나 오일처럼 미끈하고 두툼하게 느껴지는 유성감 |
| **크리미** | 전문 | 스파클링 와인의 미세하고 조밀한 거품이나 젖산 발효가 주는 포근한 질감 |
| **쨍함** | 전문 | 높은 산도가 혀를 쨍하고 예리하게 찌르는 듯한 청량하고 날카로운 자극 |
| **빳빳함** | 전문 | 탄닌이 아직 덜 풀려 거칠고 드세게 조여오는 다소 뻑뻑한 입자감 |

### [카테고리 4] 여운 (Finish)
와인을 삼키고 난 뒤 입안과 코뒤에 유지되는 후각적, 미각적 잔향을 표현합니다.

| 한국어 레이블 | 난이도 | 1줄 설명 (의미) |
| :--- | :---: | :--- |
| **깔끔함** | 입문 | 삼킨 뒤 잔여감이나 텁텁함 없이 군더더기 없이 개운하게 정리되는 느낌 |
| **긴 여운** | 입문 | 와인을 목 뒤로 넘긴 후에도 좋은 풍미가 혀와 목에 오랫동안 지속되는 느낌 |
| **짧은 여운** | 입문 | 머금을 때는 향긋하지만 삼킨 뒤 깔끔하고 빠르게 사라져 산뜻한 느낌 |
| **은은함** | 입문 | 잔잔하고 섬세한 아로마가 가볍고 평온하게 뒤에 남는 피니시 |
| **알코올 열감** | 전문 | 높은 도수로 인해 삼킨 뒤 식도와 가슴 부위가 뜨뜻하고 화끈해지는 느낌 |
| **텁텁함** | 입문 | 거친 탄닌이나 침전물, 과도한 오크 잔향 때문에 입안이 까끌하게 남음 |
| **씁쓸한 끝맛** | 입문 | 삼키고 난 뒤 혀뿌리 부분에 씁쓸하고 쌉쌀한 잔향이 약하게 맴도는 느낌 |
| **복합적 여운** | 전문 | 과일, 오크, 스파이스 등 다채로운 향이 겹겹이 스쳐 지나가며 길게 남음 |

## 3. 위스키 (위스키) 테이스팅 칩 명세

위스키는 높은 고도수의 알코올 자극과 오크통 숙성에서 우러나는 극도로 응축된 맛과 향을 표현하기 위해 **향, 맛, 질감/바디, 피니시** 4가지 카테고리로 분류합니다. (Nosing & Palate 평가법 기반)

### [카테고리 1] 향 (Nose)
위스키에 코를 대어 향을 맡았을 때 느껴지는 다양한 휘발성 아로마를 분류합니다.

| 한국어 레이블 | 난이도 | 1줄 설명 (의미) |
| :--- | :---: | :--- |
| **바닐라** | 입문 | 버번이나 아메리칸 오크 숙성에서 우러나는 가장 달콤하고 포근한 향 |
| **캐러멜** | 입문 | 설탕이나 버터를 졸인 듯한 진하고 묵직한 달콤함 |
| **피트** | 전문 | 석탄, 병원 소독약, 크레오소트, 바닷바람 등 이탄 숙성 특유의 약용 향 |
| **스모키** | 입문 | 캠프파이어, 타들어 가는 장작, 그을린 나무 등 훈연된 연기 향 |
| **시트러스** | 입문 | 레몬 껍질, 오렌지 필, 자몽 등 침샘을 자극하는 상큼하고 밝은 향 |
| **말린 과일** | 전문 | 무화과, 건포도, 대추야자 등 셰리 캐스크 특유의 달콤하고 진득한 향 |
| **견과류** | 입문 | 구운 아몬드, 호두, 밤 등 고소하고 기름진 오일 계열의 향 |
| **화사한 꽃향** | 입문 | 야생화, 제라늄, 백합 등 가볍고 산뜻하게 날리는 꽃내음 |
| **스파이시** | 전문 | 시나몬, 정향, 후추 등 코끝을 알싸하고 찌르듯이 자극하는 향신료 향 |
| **가죽/담배** | 전문 | 고숙성 위스키에서 주로 나는 중후한 가죽 시트와 마른 잎담배 향 |
| **초콜릿** | 입문 | 다크 초콜릿이나 카카오 매스처럼 쌉싸름하면서도 달콤한 향 |
| **곡물/맥아** | 전문 | 위스키의 본질인 보리 맥아, 시리얼, 갓 구운 비스킷의 구수함 |

### [카테고리 2] 맛 (Palate)
위스키를 소량 머금고 굴렸을 때 혀로 직접 감지되는 맛의 특징입니다.

| 한국어 레이블 | 난이도 | 1줄 설명 (의미) |
| :--- | :---: | :--- |
| **달콤함** | 입문 | 꿀, 설탕시럽, 캐러멜 등 맛보자마자 느껴지는 직관적이고 진한 단맛 |
| **스파이시** | 입문 | 혀를 톡 쏘거나 얼얼하게 만드는 생강, 고추, 후추 같은 매콤 알싸한 맛 |
| **쌉싸름함** | 입문 | 나무 오크통 탄닌이나 다크 카카오에서 기인하는 씁쓸하고 쌉쌀한 맛 |
| **떫은맛** | 전문 | 수축성이 강한 나무 수액 성분 등으로 인해 입안이 조이고 텁텁해지는 맛 |
| **짭조름함** | 전문 | 탈리스커 등 해안가 증류소 위스키에서 흔히 느껴지는 바닷소금의 짠맛 |
| **과일 잼** | 입문 | 신맛 없이 잘 졸여진 베리류 잼이나 달콤한 과일 청 같은 밀도 높은 맛 |
| **한약재** | 전문 | 감초, 당귀, 약초 등 깊고 진하면서 묵직한 약용 식물 특유의 단맛 |
| **고소함** | 입문 | 비스킷이나 호밀 빵을 씹는 듯 씹을수록 구수하고 든든한 보리 맛 |
| **시큼함** | 전문 | 상큼함을 넘어서 풋사과나 청포도 껍질처럼 산뜻하고 찌릿한 신맛 |

### [카테고리 3] 질감/바디 (Mouthfeel & Body)
고도수(40도 이상) 술이 입안에서 주는 물리적 밀도와 자극 정도를 분류합니다.

| 한국어 레이블 | 난이도 | 1줄 설명 (의미) |
| :--- | :---: | :--- |
| **부드러움** | 입문 | 고도수 알코올임에도 걸림이나 찌름 없이 혀 위로 매끄럽게 흐르는 느낌 |
| **기름짐** | 전문 | 밀도가 높고 유성분이 있어 입안 전체를 끈끈하게 감싸고 코팅하는 느낌 |
| **타는 듯함** | 입문 | 알코올 자극이 강해 목구멍과 혀가 화끈하고 타들어 가듯 짜릿한 느낌 |
| **가벼움** | 입문 | 오일감이나 당도가 낮아 점성이 없고 물처럼 깔끔하고 산뜻하게 흐름 |
| **크리미** | 전문 | 버터나 우유를 머금은 듯이 폭신하고 풍부하게 입안을 채우는 바디감 |
| **끈적함** | 전문 | 설탕 농축액이나 점도가 높은 시럽처럼 입안에서 쫀득하게 달라붙는 질감 |
| **날카로움** | 전문 | 스피릿의 숙성도가 낮아 알코올이 혀끝을 사정없이 톡 쏘고 찌르는 거친 질감 |
| **묵직함** | 입문 | 점도와 아로마가 가득 차서 입안에서 무게감이 느껴지는 가라앉은 바디 |

### [카테고리 4] 피니시 (Finish)
위스키를 목으로 넘기고 난 뒤 목 뒤와 비강에 머무는 잔향과 온기를 표현합니다.

| 한국어 레이블 | 난이도 | 1줄 설명 (의미) |
| :--- | :---: | :--- |
| **은은함** | 입문 | 삼킨 뒤 잔향과 따뜻함이 급격하지 않고 차분하게 오래 유지되는 느낌 |
| **긴 여운** | 입문 | 향과 열감이 목과 식도 밑에서부터 코끝까지 끊이지 않고 계속 올라옴 |
| **깔끔함** | 입문 | 알코올의 매운 기운이나 나무 탄닌 없이 맑고 산뜻하게 똑 떨어지는 끝맛 |
| **스모키 피니시** | 전문 | 삼킨 후 훈연 향과 연기 향이 목구멍 뒤에서 훈훈하게 피어오르는 피니시 |
| **알코올 스파이시** | 입문 | 넘어가고 난 뒤에도 혀와 입안에 알싸하고 매콤한 열감이 화끈하게 잔류함 |
| **떫은 끝맛** | 전문 | 삼키고 난 뒤 오크통 탄닌 때문에 혀가 건조해지고 뻑뻑함이 맴도는 느낌 |
| **짭조름한 끝맛** | 전문 | 삼킨 후 입술과 혀 주위에 소금기 같은 감칠맛이 번지는 독특한 잔향 |
| **고소한 피니시** | 입문 | 곡물의 단맛과 구수한 보리 잔향이 여운 속에 잔잔하게 조화를 이룸 |

---

## 4. 맥주 (맥주) 테이스팅 칩 명세

맥주는 발효 탄산과 몰트의 단맛, 홉의 쓴맛, 효모 발효 부산물을 고르게 드러내도록 **향, 맛, 탄산/질감, 목넘김/여운** 4가지 카테고리로 구성합니다. (Beer Flavor Wheel & BJCP 스타일 가이드라인 기반)

### [카테고리 1] 향 (Aroma)
맥주를 마시기 전 잔 위로 피어오르는 몰트와 홉, 효모의 아로마입니다.

| 한국어 레이블 | 난이도 | 1줄 설명 (의미) |
| :--- | :---: | :--- |
| **홉/풀잎** | 입문 | 생홉, 잔디, 갓 벤 풀밭 등 싱그럽고 풋풋한 식물성 향 |
| **시트러스** | 입문 | 미국식 홉에서 주로 나는 자몽, 귤, 라임, 오렌지 껍질의 상큼한 향 |
| **구수한 맥아** | 입문 | 맥아를 건조하거나 가볍게 구워 만든 빵, 비스킷, 시리얼의 구수한 향 |
| **캐러멜** | 입문 | 볶은 몰트에서 우러나는 달콤하고 그을린 캐러멜 및 토피 향 |
| **열대 과일** | 입문 | 망고, 파인애플, 파파야, 멜론 등 달콤하고 즙이 풍부한 과일 향 |
| **에스테르/바나나**| 전문 | 독일식 밀맥주 효모가 자아내는 대표적인 바나나와 알싸한 정향(Clove) 향 |
| **향긋한 꽃향** | 입문 | 야생화, 허브, 라벤더 등 은은하고 맑은 식물 꽃 향기 |
| **퀴퀴함** | 전문 | 야생 효모(브레타노마이세스) 람빅 등에서 나는 가죽, 시큼털털한 지하실 향 |
| **훈연/커피** | 전문 | 흑맥주(포터/스타우트)의 탄 맥아에서 오는 에스프레소 원두 및 탄 연기 향 |
| **솔향/송진** | 전문 | 미국식 IPA의 홉에서 주로 발현되는 쌉싸름한 소나무, 솔잎, 송진 향 |

### [카테고리 2] 맛 (Flavor)
홉의 쓴맛(IBU)과 몰트 당분의 균형(Balance)을 중심으로 표현하는 맛입니다.

| 한국어 레이블 | 난이도 | 1줄 설명 (의미) |
| :--- | :---: | :--- |
| **쌉쌀함** | 입문 | 홉에서 우러난 쓴맛이 과하지 않고 깔끔하고 단정하게 정돈된 쓴맛 |
| **구수함** | 입문 | 맥아가 선사하는 갓 구운 빵이나 볶은 곡류 특유의 친숙하고 정겨운 맛 |
| **달콤함** | 입문 | 완전 발효되지 않고 남아있는 맥아즙 당분의 달달하고 입에 착 붙는 맛 |
| **새콤함** | 전문 | 유산균 발효 맥주(사워)나 과일 맥주 특유의 새콤 짜릿하고 깨끗한 산미 |
| **떫은맛** | 전문 | 홉이나 몰트 껍질의 잔여 탄닌으로 인해 침이 마르고 입안이 조이는 맛 |
| **쌉싸름한 단맛**| 입문 | 몰트의 달콤함과 홉의 쌉쌀함이 아주 조화롭게 대조를 이루며 밀당하는 맛 |
| **밍밍함** | 입문 | 탄산 대비 몰트나 홉 풍미가 너무 옅어 물처럼 심심하고 다소 묽은 맛 |
| **초콜릿/커피** | 입문 | 검게 볶은 맥아에서 나는 쌉싸름한 다크 초콜릿과 쌉쌀한 커피 맛 |

### [카테고리 3] 탄산/질감 (Carbonation & Mouthfeel)
맥주의 기포 자극감과 입안을 채우는 바디감을 묘사합니다.

| 한국어 레이블 | 난이도 | 1줄 설명 (의미) |
| :--- | :---: | :--- |
| **청량함** | 입문 | 탄산이 살아있어 목구멍을 씻어내듯 시원하고 상쾌함을 주는 질감 |
| **부드러움** | 입문 | 거품 입자가 미세하고 질감이 유려하여 입안을 둥글게 감싸 안는 촉감 |
| **톡 쏘는 탄산** | 입문 | 탄산이 매우 강해 따갑고 찌릿하게 입천장과 혀를 자극하는 강한 청량감 |
| **묵직함** | 입문 | 높은 알코올 도수와 맥아 당분이 얽혀 입안 가득 차는 끈끈하고 무거운 바디 |
| **가벼움** | 입문 | 라거나 가벼운 에일처럼 무겁지 않고 물에 가깝게 가뿐하게 흐르는 바디 |
| **걸쭉함** | 전문 | 오트밀이나 볶지 않은 다량의 밀을 써서 끈적하고 점성이 짙게 느껴지는 질감 |
| **텁텁함** | 입문 | 탄산이 다 빠지거나 효모 및 곡물 단백질 침전물 때문에 혀가 꺼끌해짐 |
| **드라이함** | 전문 | 잔당감이 없고 입안을 보송하게 말려 마신 뒤 갈증을 남기지 않는 건조감 |

### [카테고리 4] 목넘김/여운 (Finish)
삼킬 때 넘어가는 편안함과 삼킨 후 잔여 홉/몰트 향의 지속성입니다.

| 한국어 레이블 | 난이도 | 1줄 설명 (의미) |
| :--- | :---: | :--- |
| **깔끔함** | 입문 | 삼킨 뒤 잔여 당분이나 쓴맛 없이 칼로 자른 듯 산뜻하게 정리되는 끝맛 |
| **씁쓸한 끝맛** | 입문 | IPA 등에서 삼킨 후 홉의 강한 쓴맛이 혀 뒤편에 묵직하고 길게 잔류함 |
| **개운함** | 입문 | 목구멍이 뻥 뚫리는 상쾌함과 청량한 청량감 뒤에 오는 맑은 상쾌함 |
| **화끈거림** | 전문 | 임페리얼 스타우트, 발리와인 등 고도수 맥주의 알코올 열감이 뜨겁게 남음 |
| **달콤한 여운** | 입문 | 몰트의 꿀이나 시럽 같은 단맛과 고소함이 삼킨 뒤에도 혀에 길게 지속됨 |
| **텁텁한 끝맛** | 입문 | 삼킨 뒤 홉 가루나 이스트, 거친 단백질 감각이 입안에 무겁게 남는 느낌 |
| **시큼한 피니시** | 전문 | 삼기고 난 뒤 새콤한 침이 입안 구석구석을 자극하여 시원하고 깔끔하게 끝남 |
| **부드러운 목넘김**| 입문 | 목에 걸리는 탄산의 타격이나 알코올의 쏘는 느낌 없이 유려하게 넘어감 |

## 5. 주종 공통 적용 베이스 칩 (Shared Vocabulary)
모바일 앱 개발 시, 코드 재사용성 및 공통 데이터 베이스 관리를 위해 아래 칩들은 **주종에 관계없이 공통 베이스 칩**으로 지정하여 하나의 공통 UI 컴포넌트로 활용할 수 있습니다.

| 카테고리 | 공통 칩 레이블 | 설명 |
| :--- | :--- | :--- |
| **맛 (Taste)** | **달콤함** (단맛) | 설탕, 시럽, 꿀 같은 직관적인 단맛 |
| | **쌉싸름함** (쓴맛) | 식물 껍질이나 오크, 탄 재료 등에서 오는 씁쓸함 |
| | **새콤함** (신맛) | 침샘을 자극하여 침이 고이게 만드는 깨끗한 산미 |
| | **짭조름함** (짠맛) | 미네랄리티, 소금기 등 자연스러운 소금의 맛 |
| | **스파이시** | 후추, 시나몬 등 자극적이고 얼얼하게 혀를 찌르는 맛 |
| **바디/질감** | **가벼움** | 물이나 에센스처럼 경쾌하고 얇게 흐르는 촉감 |
| | **묵직함** | 농축액처럼 부드럽고 꽉 찬 느낌을 주는 무거운 무게감 |
| | **부드러움** | 자극이나 꺼끌거림 없이 물 흐르듯 가뿐히 흘러가는 질감 |
| **여운 (Finish)** | **깔끔함** | 삼킨 후 목과 입안이 군더더기 없이 개운하게 정리됨 |
| | **긴 여운** | 삼킨 후에도 풍미가 입안과 코뒤에 선명하게 장시간 남음 |
| | **짧은 여운** | 마신 즉시 맛과 향이 날아가 깔끔하고 리프레싱함 |
| | **은은함** | 삼킨 후에 아주 잔잔하고 약한 풍미가 얇고 은근하게 감돔 |

## 6. 주종별 우선 노출(Default First) 칩 추천
모바일 뷰포트 제한으로 전체 태그를 다 보여줄 수 없을 때, '더보기' 버튼을 누르기 전 **가장 자주 사용될 대표 칩(카테고리별 상위 4~5개)**을 기본적으로 먼저 배치할 것을 추천합니다. 모두 일반 입문자 수준(입문)으로 구성하여 진입장벽을 낮춥니다.

### 와인 (와인) 우선 노출 추천 (총 16개)
* **향**: `시트러스`, `붉은 과일`, `검은 과일`, `오크`
* **맛**: `드라이`, `새콤함`, `은은한 단맛`, `잘 익은 과일`
* **바디/질감**: `가벼움`, `묵직함`, `부드러움`, `떫은맛`
* **여운**: `깔끔함`, `긴 여운`, `짧은 여운`, `은은함`

### 위스키 (위스키) 우선 노출 추천 (총 16개)
* **향**: `바닐라`, `캐러멜`, `스모키`, `시트러스`
* **맛**: `달콤함`, `스파이시`, `쌉싸름함`, `고소함`
* **질감/바디**: `부드러움`, `타는 듯함`, `묵직함`, `가벼움`
* **피니시**: `긴 여운`, `깔끔함`, `은은함`, `알코올 스파이시`

### 맥주 (맥주) 우선 노출 추천 (총 16개)
* **향**: `홉/풀잎`, `시트러스`, `구수한 맥아`, `열대 과일`
* **맛**: `쌉쌀함`, `구수함`, `달콤함`, `쌉싸름한 단맛`
* **탄산/질감**: `청량함`, `부드러움`, `톡 쏘는 탄산`, `가벼움`
* **목넘김/여운**: `깔끔함`, `개운함`, `부드러운 목넘김`, `씁쓸한 끝맛`
