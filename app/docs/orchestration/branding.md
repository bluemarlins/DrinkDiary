# Phase 1 결과물 — 상품화 준비 (브랜딩 / 기능 스펙)

Phase 1(`product-plan.md` 4-1절, `task-log.md` Phase 1)의 산출물을 정리한 문서. `agy`가 생성한
브레인스토밍/카피 초안(P1-1, P1-4, P1-7)을 Claude가 검토·선택·확정(P1-2, P1-3, P1-5, P1-6)한
결과다. **이름·아이콘 방향은 Claude의 추천안이며 최종 확정 전 사용자 확인이 필요하다.**

## 1. 애플리케이션 이름 (추천 — 사용자 확인 필요)

`agy`(gemini-3.5-flash-medium)가 생성한 한국어 5안 + 영문 5안 중 Claude 추천:

- **1순위: 그날의 팔레트** — "정직한 팔레트"라는 브랜드 가치와 직접 연결되고, 시적이면서도 스토어
  검색 노출 시 기억에 남는 이름. 아래 스토어 설명 초안도 이 이름 기준으로 작성됨.
- **2순위(상표 충돌 위험 최소): 안온한 잔** — agy 판단상 동종 업계 사용 빈도가 낮아 가장 안전.
- 기존 가칭 "DrinkDiary"는 일반 명사 조합이라 스토어 차별화가 어려워 유지하지 않는 것을 추천.
- 전체 후보 목록(한국어 5 + 영문 5, 판단 근거 포함)은 `agy` conversation `2440f94f` 계열 —
  실행 로그: `agy -p "..." --model gemini-3.5-flash-medium`, conversation_id
  `fe5823a5-a196-4a7f-86ee-c66c5cd4caa8`에서 재현 가능.
- **참고**: 상표/도메인/스토어 중복 여부는 agy도 실시간 조회 없이 추정한 것이므로, 최종 확정 전
  Play Console에서 실제 이름 중복 검색이 필요하다.

## 2. 가치 제안 (Value Proposition)

> 나만의 술 취향을 가장 정직하게 기록하고 다시 찾아보는, 서버 없는 평생 보관용 술 일기장.

핵심 가치 3가지:
1. **완전한 소유권**: 계정 없음, 서버 없음 — 기록은 오직 내 기기에만 존재.
2. **정직한 개인 기록**: 소셜 압력 없이 재구매 여부를 솔직하게 판단.
3. **통합된 취향 시야**: 와인·위스키·맥주를 하나의 대시보드로 가로질러 보는 유일한 개인 아카이브.

## 3. 브랜딩 방향

- **톤앤매너**: 조용하고 담백한 개인 아카이브. 소셜/게임화 요소 지양, 과장된 마케팅 톤 지양.
- **키워드**: 셀러(Cellar), 조용한 의식(Quiet ritual), 개인 아카이브, 정직한 팔레트.
- **컬러**: 이미 `ui/theme/Color.kt`/`Theme.kt`에 구현된 팔레트를 그대로 브랜드 컬러로 채택 —
  보틀그린(Primary, `#2F6F4E`), 몰트 앰버(Secondary, `#9C6722`), 와인베리(Tertiary, `#93425E`),
  따뜻한 종이색 배경(`#FFF8F2`). 세 주종을 상징하는 색이 이미 앱 전체 테마와 일치하므로 별도 브랜드
  컬러 신규 정의가 필요 없다.

## 4. Play 스토어 설명 (agy 초안, Claude 검토 완료 — 이름 확정 시 문구의 앱 이름만 교체)

**짧은 설명(80자 이내)**
> 서버 없이 내 기기에 안전하게 기록하는 나만의 차분한 술 일기장

**긴 설명**

어떤 술을 마셨는지 자랑하기 위한 기록이 아닌, 오직 나만을 위한 정직한 취향의 기록을 시작해보세요.

[앱 이름]은 와인, 위스키, 맥주 등 당신이 마주한 술과의 순간들을 조용히 채워나가는 개인 아카이브
앱입니다. 타인의 시선이나 복잡한 소셜 기능 없이, 차분하고 담백하게 당신만의 술 일기를 적어 내려갈
수 있습니다.

주요 기능:
- 제한 없는 자유로운 기록 — 주종 상관없이 테이스팅 노트와 감상을 무제한 기록
- 기기 내 안전한 보관 — 서버 전송 없이 기기에만 저장, 개인정보 유출 우려 없는 평생 아카이브
- 한눈에 돌아보는 취향 대시보드 — 주/월/년 단위 요약
- 종류·상태별 컬렉션 필터와 검색

추가 예정 기능: 데이터 백업/내보내기, 개인 맞춤형 인사이트 도구.

**핵심 키워드 후보**: 술일기, 테이스팅노트, 와인기록, 위스키노트, 맥주기록, 개인아카이브, 술도감,
취향기록, 혼술일기, 오프라인일기장

## 5. Free 기능 최종 스펙

MVP에서 이미 구현된 범위를 그대로 Free 티어로 확정한다(추가 제한 없음):
- 기록 CRUD 무제한 (와인/위스키/맥주, 사진/가격/장소/테이스팅노트/별점/컬렉션상태/기록일시)
- 대시보드 요약 (주/월/년, 평균 별점, 종류별 분포, 재구매후보/비선호 카운트)
- 컬렉션 필터 (종류 + 상태 복합 필터)
- 검색

## 6. 프리미엄(Advance) 기능 최종 스펙 (Billing 게이팅 대상, 우선순위순)

Phase 2에서 구현하고, Phase 3에서 Billing으로 게이팅한다.

   `ObserveDashboardSummaryUseCase` 패턴을 확장하는 신규 UseCase로 구현.

3. **커스텀 테마 / 홈 화면 위젯** — 우선순위 가장 낮음, Phase 2 후반 또는 Phase 2 다음 이터레이션.

클라우드 동기화/멀티 디바이스는 여전히 범위 밖(Phase 4 이후 후보로만 유지).

## 7. App Icon 컨셉 (agy 초안, 3안 — 방향 선택 필요)

`agy`(gemini-3.6-flash-high)가 기존 Material 3 팔레트를 반영해 제안한 3가지 방향. SVG 스케치
원본은 conversation_id `e24a39f0-b513-420a-9457-63f870125116`에서 재현 가능.

| 컨셉 | 모티프 | 인상 |
| --- | --- | --- |
| 1. The Private Cellar & Drop | 셀러 키홀 + 3주종이 섞인 테이스팅 드롭 | 가장 직관적, "나만의 비밀 저장고" 식별성 높음 |
| 2. Archival Ledger & Triple Tab | 기록장 페이지 + 3색 인덱스 탭 | "기록/노트" 성격 가장 강함, Material 3 UI와 톤 일치 |
| 3. Tasting Glass Stamp & Aging Ring | 겹쳐진 3개의 잔 자국 링 | 가장 감성적/미니멀, 프리미엄 느낌 |

**Claude 추천: 컨셉 2 (Archival Ledger & Triple Tab)** — 앱의 실제 정체성(기록/아카이브 도구)과
가장 직접적으로 맞고, 이미 구현된 Material 3 UI 톤과 자연스럽게 이어진다. 단, **이 SVG 스케치는
방향성 확인용이며, 실제 adaptive icon(전경/배경 레이어, 다양한 밀도) 프로덕션 에셋 제작은 별도
작업(디자인 툴 또는 후속 태스크)이 필요하다.**
