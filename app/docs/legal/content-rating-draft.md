# 콘텐츠 등급(IARC) 설문 답변 초안

## 문서 정보

- 작성: Claude (Phase 1), 사용자 검수 필요
- 상태: **초안 — Play Console의 실제 IARC 설문 문항/문구는 이 문서 작성 이후 바뀌었을 수 있으므로 제출 시점에 화면 문항과 대조**
- IARC(International Age Rating Coalition) 설문은 Play Console 내에서 진행하며, 이 문서는 각 문항에 어떻게 답할지 미리 검토한 것이다.

---

## 핵심 이슈: 알코올 콘텐츠

DrinkDiary는 **주류(와인/위스키/맥주) 기록**이 앱의 핵심 기능이므로, IARC 설문의 "알코올 관련 내용을 포함하거나 참조합니까?" 문항에 **"예"**로 답해야 한다. 이는 정직하게 답변해야 하는 항목이며, 허위로 "아니요"를 선택하면 이후 Google의 사후 검토에서 등급이 재조정되거나 제재를 받을 수 있다.

- 예상 영향: 완전 전연령(Everyone) 등급보다는 한 단계 위(예: Google Play "Teen" 상당) 등급으로 책정될 가능성이 높음. 다만 실제 등급은 IARC 알고리즘이 전체 답변 조합으로 산정하므로 최종 등급은 설문 제출 후 확정된다.
- 이 등급으로 인해 Google Play "패밀리(Designed for Families)" 프로그램 대상에서는 제외된다 (원래도 대상이 아니었을 가능성이 높음).
- 광고 SDK(Phase 2, AdMob) 연동 시 성인/알코올 관련 콘텐츠 등급이 특정 광고 카테고리(예: 아동 대상 광고)의 게재 제한에 영향을 줄 수 있다 — Phase 2에서 AdMob 콘텐츠 등급 설정과 함께 재확인.

## 예상 문항별 답변

| 문항 카테고리 | 예상 답변 | 근거 |
|---|---|---|
| 폭력적 콘텐츠 | 아니요 | 앱에 폭력 묘사 없음 |
| 성적 콘텐츠/노출 | 아니요 | 해당 없음 |
| 욕설/비속어 | 아니요 (단, 사용자가 테이스팅 노트에 자유 입력하는 텍스트는 통제 불가) | 앱 자체 제공 콘텐츠에는 욕설 없음. 사용자 입력 필드는 비공개(로컬 저장, 타 사용자에게 노출되지 않음)이므로 UGC 노출 리스크 낮음 |
| **주류(알코올) 참조/묘사** | **예** | 앱의 핵심 기능이 주류 기록 |
| 담배 참조 | 아니요 | 해당 없음 |
| 마약 참조 | 아니요 | 해당 없음 |
| 도박 | 아니요 | 해당 없음 |
| 사용자 간 상호작용/UGC 공개 공유 | 아니요 | 소셜/공유 기능 없음, 기록은 기기 로컬에만 저장 |
| 위치 공유 | 아니요 | '장소'는 자유 텍스트 입력이며 GPS/위치 권한을 사용하지 않음 |
| 디지털 구매(인앱 결제) | 현재: 아니요 / 향후 "광고 제거 IAP" 도입 시 재제출 필요 | `service-launch-roadmap.md` Phase 2에서 검토 중인 항목 |
| 개인정보 공유 | 아니요 | `privacy-policy.md` 참조 |
