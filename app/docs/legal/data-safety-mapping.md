# Play Console 데이터 안전성(Data Safety) 섹션 답변 매핑

## 문서 정보

- 작성: Claude (Phase 1), 사용자 검수 필요
- 상태: **초안 — Play Console 실제 설문 문항은 주기적으로 바뀌므로 제출 시점에 문항을 다시 대조할 것**
- 이 문서는 Play Console > 앱 콘텐츠 > 데이터 보안(Data safety) 설문에 어떻게 답변할지 미리 정리한 것이다. 실제 제출은 Play Console 화면에서 직접 진행한다.

---

## 현재 코드 기준 (Phase 1 시점, AdMob 연동 전)

DrinkDiary는 로컬 우선 앱으로, `data/local/DrinkRecordEntity`에 정의된 데이터(주류 종류, 이름, 사진 URI, 가격, 장소, 테이스팅 노트, 별점, 컬렉션 상태, 시각)는 **기기 밖으로 전송되지 않는다.** Google의 Data Safety 기준상 '수집(collection)'은 데이터가 기기 밖으로 전송되는 것을 의미하므로, 현재 코드 기준으로는:

| 질문 | 답변 |
|---|---|
| 앱이 사용자 데이터를 수집하거나 공유합니까? | **아니요 (No data collected)** |
| 데이터가 암호화되어 전송됩니까? | 해당 없음 (전송 자체가 없음) |
| 사용자가 데이터 삭제를 요청할 수 있습니까? | 해당 없음 — 이용자가 앱 내에서 직접 삭제하거나 앱 삭제로 즉시 제거 가능 |

## Phase 2(AdMob 연동) 이후 예상 답변

AdMob SDK를 붙이면 광고 식별자 등이 Google에 전달되므로 답변이 바뀐다. 실제 연동 시 AdMob SDK 문서의 최신 데이터 수집 항목과 대조해서 확정할 것.

| Data Safety 카테고리 | 수집 여부 | 목적 | 공유 여부 |
|---|---|---|---|
| 기기 또는 기타 ID (광고 식별자) | 예 | 광고(Advertising or marketing) | Google(AdMob)에 공유 |
| 앱 활동 (앱 상호작용, 인앱 검색 기록 등 — AdMob 표준 수집 항목) | 예 (SDK 표준 동작) | 광고 | Google에 공유 |
| 위치정보(대략적) | **확인 필요** — AdMob 기본 설정에서 위치 기반 광고를 껐는지에 따라 다름 | 광고 | 사용 시 Google에 공유 |
| 개인 정보(이름, 이메일 등) | 아니요 | — | — |
| 사진/동영상, 파일 | 아니요 (URI만 로컬 참조, 전송 없음) | — | — |
| 재무 정보 | 아니요 | — | — |

공통 답변:
- **모든 사용자 데이터를 암호화하여 전송합니까?** → 예 (Google SDK 표준 HTTPS)
- **사용자가 데이터 삭제를 요청할 수 있는 방법을 제공합니까?** → 계정 기반 서버 데이터가 없으므로 "해당 없음" 또는 기기의 광고 ID 재설정 안내로 대체
- **데이터 처리가 검증되었습니까(Independent security review)?** → 아니요(소규모 개인 개발자 앱 기준 일반적으로 해당 없음)

## Play Console 제출 전 체크리스트

- [ ] Phase 2 AdMob 통합 완료 후 실제 사용하는 광고 포맷(배너/전면/네이티브/보상형)별로 AdMob 공식 문서에서 데이터 수집 항목 재확인
- [ ] 위치정보 수집 옵션을 껐는지 코드에서 확인 후 표에 반영
- [ ] Play Console 설문 문항이 이 문서 작성 시점과 달라졌는지 대조
