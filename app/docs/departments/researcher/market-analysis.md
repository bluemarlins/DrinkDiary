## 2. "Killer Features" for Premium Conversion
사용자가 결제를 결심하게 만드는 카테고리 내 핵심 유료 기능(Killer Features)은 다음과 같습니다.

1.  **데이터 소유권 및 내보내기 (Data Export):** 자신이 기록한 수백 개의 노트를 CSV/PDF로 백업하고 싶어 하는 고급 사용자들의 니즈가 강력함.
2.  **정밀한 분석 및 인사이트 (Advanced Analytics):** "내가 가장 좋아하는 산지/포도 품종/도수" 등 단순 기록을 넘어선 개인 맞춤형 데이터 통계.
3.  **라벨 스캔 (AI/OCR):** 텍스트를 일일이 입력하는 번거로움을 줄여주는 고성능 라벨 스캔 서비스.
4.  **광고 없는 쾌적한 UX (Ad-free):** 개인적인 기록 공간(다이어리)에서 외부 광고가 흐름을 깨는 것을 극도로 꺼림.
5.  **셀러 관리 기능 (Cellar Management):** 보유한 술의 위치, 구매 가격, 최적 시음 기한(Drink by date) 알림 등 자산 관리 성격의 기능.
6.  **무제한 기록 (Unlimited Entries):** 무료 버전에서는 기록 개수를 제한하고, 프리미엄에서 무제한 제공.

## 3. 수익화 모델 분석: 광고(Ads) vs. 기능 제한(Feature Gating)
최근 제안된 'Google AdMob + 광고 제거 구매' 모델과 '기능 제한형 무료 버전' 모델을 비교 분석한 결과입니다.

### 3.1 Google AdMob 도입의 영향 (Privacy vs. Revenue)
*   **브랜드 가치 충돌:** 'Taste Archive'의 핵심 가치인 "Privacy-first, Local-first"와 AdMob의 데이터 수집 정책(ADID, IP, 개인화 타겟팅 등)은 정면으로 충돌함. 사용자는 "내 데이터가 기기에만 머문다"는 약속이 깨졌다고 느낄 위험이 큼.
*   **기술적 부채:** AdMob SDK(및 UMP SDK) 도입은 앱 크기 증가 및 프라이버시 정책(Data Safety) 공시 복잡도를 높임.
*   **프라이버시 친화적 대안:** 
    *   **Contextual Ads (문맥 광고):** 사용자 정보가 아닌 '현재 보고 있는 술의 종류'에 기반한 광고. 단, 모바일 SDK 수준에서 이를 완벽히 프라이버시 친화적으로 제공하는 대형 네트워크는 드묾.
    *   **In-house Sponsorships:** 특정 브랜드(위스키 증류소 등)와의 직접 제휴를 통한 고정 배너. SDK 트래킹이 없어 가장 안전함.

### 3.2 수익 모델 비교 분석

| 구분 | 광고형 (Free with Ads) | 기능 제한형 (Free Basic) |
| :--- | :--- | :--- |
| **유저 획득 (UA)** | 진입 장벽이 매우 낮음 | 핵심 기능 사용 제한 시 이탈 가능성 |
| **수익성 (Revenue)** | 다수의 유저 확보 시 안정적 소액 수익 | 결제 전환율(Conversion)에 의존 |
| **브랜드 이미지** | 일반적인 무료 앱 느낌 | 전문적이고 프라이빗한 프리미엄 도구 |
| **데이터 프라이버시** | SDK를 통한 데이터 공유 발생 가능 | 데이터 완벽 통제 가능 |

## 4. User Sentiment: Privacy & Local Storage
유틸리티 및 다이어리 앱 카테고리에서의 사용자 여론 조사 결과 (Reddit 및 스토어 리뷰 기반):

*   **프라이버시(Privacy)에 대한 민감도:** 술이라는 주제는 건강 및 개인적인 습관과 직결되므로, 데이터가 서버에 저장되거나 타인에게 노출되는 것에 대한 거부감이 상당히 높음. "나만 보는 공간"에 대한 수요가 존재함.
*   **로컬 저장소(Local-only)의 선호도:** 
    *   **장점:** 네트워크 없이도 즉각적인 반응 속도(Speed), 데이터 오남용 걱정 없음.
    *   **단점:** 기기 분실 시 데이터 유실에 대한 공포. 따라서 '로컬 퍼스트'이되 '프라이빗 백업(구글 드라이브 등)' 옵션이 필수적으로 요구됨.
*   **탈소셜(No Social) 트렌드:** 기존 앱들이 지나치게 소셜화(SNS화)되어 피로감을 느끼는 사용자들이 "순수하게 기록에만 집중할 수 있는 앱"을 찾는 경향이 뚜렷해짐.

## 5. 'Taste Archive' Positioning Comparison
현재 우리 앱의 포지셔닝과 시장 기회 분석입니다.

| 구분 | 경쟁사 (Vivino, Untappd 등) | 테이스트 아카이브 (Taste Archive) | 분석 및 기회 |
| :--- | :--- | :--- | :--- |

| **수익 모델** | 광고 및 데이터 판매 병행 | 순수 기능 유료화 (추천) | 광고 없는 클린한 환경 자체가 프리미엄 가치 |

## 6. 결론 및 제언 (Market Insights)
1.  **광고 도입 지양:** 'Local-first'와 'Privacy'라는 강력한 차별화 요소를 훼손할 위험이 큼. AdMob 도입보다는 '기능 제한형 무료 버전(Freemium)'을 권장함.
2.  **수익화 허들 낮추기:** 구독(Subscription) 모델은 사용자에게 심리적 부담을 주므로, **'Lifetime Pro (평생 소장권)'** 또는 **'기능별 개별 구매'** 방식을 고려하여 초기 수익화 가속화.
3.  **데이터 내보내기(Export) 및 무제한 저장:** 이를 핵심 유료 전환 포인트로 설정.
4.  **브랜드 메시지 강화:** "광고를 위해 당신의 취향을 추적하지 않습니다"라는 메시지를 통해 AdMob을 사용하는 경쟁사들과의 격차를 벌림.
