## 1. 재생성 이유

기존 확정 아이콘(컨셉 2 "Archival Ledger & Triple Tab")은 **3색 인덱스 탭이 와인·위스키·맥주**를
가리켰다. 맥주가 범위에서 빠지면서(`../../specs/planner/problem-definition.md` 7-1절) 의미가 하나
비었다. 또한 브랜드 톤이 "조용한 아카이브"(수집가 톤)에서 **"쉬운 도구, 자랑스러운 결과"**로
바뀌었다(`../../specs/designer/branding.md` 2-1절).

## 2. 후보

전부 512×512 기준으로 지시했으나 실제 산출은 1024×1024 **JPG**다. 채택 후 PNG로 재생성해야 한다
(adaptive icon foreground는 투명 배경 필요).

| 안 | 모티프 | 파일 |
| --- | --- | --- |
| **A. 두 잔의 실루엣** | 와인잔(와인베리) + 위스키 로우볼(몰트앰버), 보틀그린 배경 | `concept-a-glasses.jpg` |
| **B. 쌓이는 기록** | 카드 3장이 층층이 쌓인 형태, 종이색 배경 | `concept-b-stack.jpg` |
| **C. 취향의 표식** | 종이색 북마크 안에 와인병 + 위스키잔, 보틀그린 배경 | `concept-c-bookmark.jpg` |

## 4. 평가

### A. 두 잔의 실루엣 — **권장**

- **강점**: 48px에서 유일하게 "와인+위스키 앱"으로 읽힌다. 이것이 우리의 최대 차별점
  (통합 기록)을 아이콘이 직접 말해주는 것이기도 하다. 브랜드 3색이 정확히 쓰였다.
- **약점**: 잔 모티프는 주류 앱에서 흔하다. 차별성은 색과 조합에서만 나온다.
- 채택 시 다듬을 것: 위스키 잔이 와인잔에 비해 존재감이 약하다. 두 잔의 시각적 무게를 맞추면
  "두 주종을 동등하게 다룬다"는 메시지가 강해진다.

### B. 쌓이는 기록 — **반려**

"축적"이라는 제품 가치를 가장 세련되게 표현했고 형태도 단순하다. 그러나 **아이콘만 보고 술 앱임을
알 수 없다** — 메모·생산성 앱으로 읽힌다. 스토어와 런처에서 인지되지 않는 아이콘은 미학과 무관하게
실패다.

추가 문제: 카드가 **3층**인데 주종은 2개다. 구 아이콘의 "3색인데 주종은 2개" 문제를 그대로 반복한다.

### C. 취향의 표식 — 보류

북마크 = "내 기준으로 표시해 둔다"는 의미는 제품과 잘 맞는다. 그러나 요소가 많아
(북마크 + 병 + 라벨 + 잔) 작은 크기에서 무너진다. **요소를 하나로 줄이면**(예: 북마크 안에 잔 하나만)
살아날 수 있으나, 그러면 두 주종을 못 보여준다.

## 5. 권장

> **A 채택 후 위스키 잔의 시각적 무게 보강.**

근거는 미감이 아니라 판독성이다 — 세 안 중 48px에서 제품 정체성을 전달하는 것은 A뿐이다.
C의 "표식" 개념이 아깝다면, 그것은 아이콘이 아니라 **앱 내 컬렉션 상태 UI**에서 살리는 편이 낫다.

## 6. 채택 후 필요한 작업

1. **PNG 재생성** — adaptive icon foreground용 투명 배경(RGBA). 현재 산출물은 JPG라 그대로 못 쓴다.
2. 밀도별 리사이즈 후 `res/mipmap-*`에 반영 (Claude가 직접 수행 — 정밀 리소스 배치는 위임하지 않음)
3. `ic_launcher_background.xml` 색상 확인 (현재 보틀그린 단색)
4. `../../specs/designer/branding.md` 5절(App Icon) 갱신
5. Play 스토어 등록용 512×512 불투명 아이콘 별도 보관
