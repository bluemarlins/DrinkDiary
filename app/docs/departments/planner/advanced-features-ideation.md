# Advanced(Premium) 기능 아이디어 백로그

`../../specs/designer/branding.md` 6절에서 확정한 3대 프리미엄 기능(고급 인사이트, CSV 내보내기, 커스텀
테마/위젯) 이후 후보로 검토할 아이디어. `agy`(gemini-3.5-flash-medium) 브레인스토밍 결과를 Claude가
검토·정정한 것이다. **아직 사용자 확정 전 — Phase 2 완료 후 우선순위 논의 대상.**

## 검토 중 발견한 사실 정정

agy가 제안한 "정밀 아로마 휠 & 미각 레이더 차트"는 **이미 무료 기능으로 구현되어 있다**
(`DrinkRatingBreakdown` + `DDRatingBreakdownRadarChart`, `RecordDetailScreen`/`RecordEditorScreen`에서
주종별 `ratingCriteria()`로 감각 요소를 레이더 차트로 기록·표시 중). 신규 프리미엄 후보에서 제외.

## 로컬 전용으로 구현 가능한 후보 (서버 불필요)

| 아이디어 | 가치 | 난이도(추정) | 비고 |
| --- | --- | --- | --- |
| 블라인드 테이스팅 모드 | 선입견 없는 기록, 브랜드 톤과 잘 맞음 | 낮음 | 입력/노출 순서만 제어하면 됨. 다음 후보 1순위 추천 |
| 온디바이스 취향 매칭도 계산기 | 신규 구매 결정 보조, 데이터 축적 유인 | 중간 | 기존 평점/컬렉션 데이터만으로 유사도 계산, 서버 불필요 |
| 개인 셀러 인벤토리 관리(구매가/보관위치/음용 적기) | 컬렉션 자산 관리 | 중간~높음 | **새 도메인 모델 필요**(기록과 별개의 "보유 재고" 개념) — 별도 아키텍처 설계 필요, Phase 3+ 후보 |
| 시음 도감 PDF 내보내기 | 실물처럼 소장 가능한 백업 | 중간 | CSV 내보내기(Phase 2)의 자연스러운 후속. 구 `product-plan.md`(폐기)에 "PDF는 2차 검토"로 언급됐던 항목 |
| 온디바이스 라벨 OCR 자동완성 | 입력 피로도 감소 | 중간 | ML Kit 등 온디바이스 OCR SDK 의존성 추가 필요 |

## 서버/클라우드가 필요해 현재 범위 밖인 후보

| 아이디어 | 비고 |
| --- | --- |
| 멀티 디바이스 동기화 + 읽기 전용 웹 링크 공유 | `../../specs/planner/design-principles.md` 쟁점 2에서 **서버 도입은 반려**로 확정됨 |
| 글로벌 주류 DB 연동 바코드 검색 | 대규모 외부 DB/API 의존 — 현재 로컬 우선 원칙과 상충, 별도 검토 필요 |

## Claude 추천 우선순위 (다음 논의 후보)

1. 블라인드 테이스팅 모드 — 난이도 낮고 브랜드 정체성과 가장 잘 맞음
2. 시음 도감 PDF 내보내기 — CSV 내보내기 완료 후 바로 이어서 검토 가능
3. 취향 매칭도 계산기 — 데이터가 쌓일수록 가치가 커지는 리텐션 기능

인벤토리 관리와 OCR은 가치는 높지만 각각 새 도메인 모델/외부 SDK가 필요해 별도 설계 논의를
거친 뒤 착수하는 것을 권장한다.
