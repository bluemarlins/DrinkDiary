# DrinkDiary Product Plan

## 1. 문서 목적

이 문서는 DrinkDiary를 Google Play Store에 낼 수 있는 상품으로 발전시키기 위한 비즈니스 모델과
기능 로드맵을 정의한다. `usecase.md`/`ui-flow.md`가 현재 MVP의 기능 범위를 다루는 것과 달리, 이
문서는 수익화 전략과 Phase별 확장 계획을 다룬다. 실행 태스크 단위 분해는
`orchestration/task-log.md`에서 관리한다.

> **참고**: "DrinkDiary"는 프로젝트/패키지 내부 코드명이다. 사용자 대면 확정 브랜드명은
> **테이스트 아카이브 / Taste Archive**이며, 상세 근거는 `orchestration/branding.md` 1절 참고.

## 2. 타깃 사용자

기존 README의 제품 스코프를 유지한다: 와인/위스키/맥주를 즐기는 개인이 자신의 취향을 기록하고
재구매 여부를 판단하기 위한 개인 컬렉션 앱. 계정, 소셜 기능, 추천 알고리즘, 외부 주류 DB 연동은
현재 스코프에 포함하지 않는다. 프리미엄 티어에서도 "개인 기록 도구"라는 정체성은 유지하고, 그
안에서 더 깊은 인사이트와 데이터 관리 편의를 유료로 제공하는 방향으로 한정한다.

## 3. 비즈니스 모델: 부분 유료화 (Freemium)

광고 없이, 무료 티어로 핵심 경험을 완결시키고 프리미엄 티어는 "더 잘 쓰는 사람을 위한 확장"으로
포지셔닝한다.

### Free 티어 (현재 MVP 그대로)
- 기록 CRUD 무제한
- 기본 대시보드(주/월/년 요약, 평균 별점, 종류별 분포)
- 컬렉션 필터(종류 + 상태)
- 검색

### Premium 티어 (구독 또는 1회 인앱결제 — Phase 1에서 과금 방식 확정)
- **고급 인사이트**: 기간별 취향 트렌드, 가격대별 만족도 분석, 재구매율 추이
- **데이터 백업/내보내기**: CSV/PDF 내보내기, 로컬 백업 파일 생성·복원
- **커스텀 테마 / 홈 화면 위젯**
- **클라우드 동기화·멀티 디바이스**: 백엔드 인프라가 필요한 별도 아키텍처 결정 사항이므로
  Phase 3 이후 후보로만 남겨두고 지금 범위에는 포함하지 않는다.

과금(Google Play Billing Library 연동, entitlement 검증)은 **의도적으로 가장 마지막 기술 작업으로
미룬다** — 상품 방향(이름/브랜딩/기능 범위)이 먼저 확정되어야 어떤 기능을 프리미엄으로 게이팅할지
설계가 의미 있기 때문이다.

## 4. Phase 로드맵

| Phase | 목표 | 상태 |
| --- | --- | --- |
| Phase 0 | 하네스/스캐폴딩 구축 (문서 구조, 코드 일관성 장치, agy 오케스트레이션 파이프라인) | 완료 |
| Phase 1 | **상품화 준비**: 앱 이름·가치제안·브랜딩·스토어 설명·주요 기능/프리미엄 기능 스펙·아이콘 방향 확정 (코드 작성 없음) | 진행 중 |
| Phase 2 | MVP 고도화 구현: Free 기능 다듬기 + Phase 1에서 확정한 프리미엄 후보 기능 실제 구현, UI 고도화 | 예정 |
| Phase 3 | Billing 연동 (Google Play Billing Library, entitlement 게이팅) — 프리미엄 기능이 실제로 완성된 뒤 마지막에 부착 | 예정 |
| Phase 4 | 스토어 출시 준비(정책 점검, 스토어 리스팅, 성능/크래시/접근성 점검, 실제 게시) | 예정 |

각 Phase는 착수 시점에 `orchestration/task-log.md`에 구체적 태스크로 분해되어 등록된다. Phase
경계마다 사용자에게 진행 상황을 요약 보고하고 다음 Phase 착수 여부를 확인한다.

## 4-1. Phase 1 상세: 상품화 준비 체크리스트

실제 기능 구현에 들어가기 전에 아래 항목을 먼저 확정한다. 담당 배분과 진행 상태는
`orchestration/task-log.md`의 Phase 1 표에서 관리하고, 확정된 결과물은 이 문서와
`orchestration/branding.md`(신규)에 반영한다.

1. **애플리케이션 이름/네이밍** — 브랜드 후보군 확보 후 최종 선정
2. **가치 제안(Value Proposition)** — 한 문장 포지셔닝 + 3대 핵심 가치
3. **브랜딩** — 톤앤매너, 브랜드 컬러 방향(기존 `ui/theme` 팔레트와의 정합성), 아이덴티티 키워드
4. **Application 설명** — Play 스토어 짧은 설명(80자)/긴 설명, 핵심 키워드
5. **주요 기능(Free) 최종 스펙** — 3절의 초안을 UX 흐름 수준으로 확정
6. **프리미엄(Advance) 기능 최종 스펙** — Billing 게이팅 대상이 될 구체적 기능 목록과 우선순위
7. **App Icon 방향** — 컨셉 방향 2~3안 (실제 프로덕션 품질의 최종 아이콘 에셋은 별도 디자인 툴
   작업이 필요할 수 있음을 감안, 여기서는 방향성/컨셉까지 확정)

## 5. 경쟁/벤치마킹 조사 (Phase 0 산출물, agy 위임)

`orchestration/agy-playbook.md`의 "벤치마킹 조사" 템플릿으로 `agy`(gemini-3.5-flash-medium)에
위임해 조사한 결과다. **가격/요금제 수치는 agy가 생성한 내용으로 실시간 스토어 조회가 아니므로,
Phase 1에서 실제 과금 정책을 확정하기 전에 Play Store에서 직접 재확인이 필요하다.**

| 앱 | 주종 | 무료 | 프리미엄 | 가격(agy 조사, 재확인 필요) |
| --- | --- | --- | --- | --- |
| Vivino | 와인 | 라벨 스캔, 평점 조회, 기본 기록 | 레스토랑 와인리스트 스캔, 맞춤 매칭 점수, 셀러 가치 추적, 광고 제거 | 월 $4.99 / 연 $47.90 |
| Untappd | 맥주 | 체크인, 기본 평점, 소셜 피드 | 정밀 평점, 통계 대시보드, CSV/JSON 내보내기 | 월 $5.99 / 연 $54.99 |
| Distiller | 위스키/증류주 | 검색, 바코드 스캔, 기본 컬렉션 | 맛 필터 검색, 시장가치 추적, 데이터 내보내기, 광고 제거 | 월 $4.99 / 연 $48.00 |
| My Cocktail Bar | 칵테일 | 재료 등록, 기본 레시피 추천 | 다중 바 관리, 라벨 AI 인식, 프리미엄 레시피 | 1회 구매 ~$2-10 또는 월 ~$1.99 |

공통 패턴: 경쟁 앱들은 대체로 (1) 상세 통계/시각화, (2) 데이터 내보내기/백업, (3) 광고 제거를
프리미엄 축으로 삼는다 — 이는 3절의 DrinkDiary 프리미엄 티어 설계와 방향이 일치한다.

**DrinkDiary 차별화 포지셔닝**: 경쟁 앱 대부분이 서버 기반 소셜/커머스 앱인 반면, DrinkDiary는
"서버 없는 완전한 개인 프라이버시 로컬 다이어리"로 포지셔닝한다 — 계정 없이 평생 소장 가능한
기록, 다수 주종(와인/위스키/맥주) 통합 대시보드를 무료로 제공하고, 그 위에 고급 인사이트/백업을
프리미엄으로 얹는다. (전체 조사 원문은 `orchestration/task-log.md`의 P0-4 항목에서 실행 로그로
재현 가능.)
