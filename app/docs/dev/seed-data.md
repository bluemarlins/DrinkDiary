## 시딩 메커니즘 (Claude 구현, 2026-08-08)

위 30건은 실제 코드에서 `app/src/debug/java/com/bluemarlin/drinkdiary/debug/DebugSeeder.kt`에 하드코딩되어 있고, 이미지 프롬프트는 agy(`gemini-3.6-flash-high`)가 생성한 오리지널 일러스트로 `app/src/debug/assets/seed_images/{wine,whiskey,beer}_NN.jpg`에 저장돼 있다(실제 라벨 사진 아님 — 브랜드 텍스트/로고 없는 스타일화된 일러스트).

- **동작 방식**: `DrinkDiaryApplication.onCreate()`가 매번 `DebugSeeder.seedIfNeeded()`를 호출하지만, 기존 기록이 1건이라도 있으면 즉시 종료한다(중복 삽입 없음). 앱 데이터를 초기화(`adb shell pm clear com.bluemarlin.drinkdiary` 또는 설정에서 저장공간 지우기)하면 다음 실행 시 다시 채워진다.
- **날짜 분산**: 각 항목의 `recordedAtMillis`는 "지금으로부터 N일 전"으로 계산되므로(하드코딩된 절대 날짜 아님), 언제 시딩이 실행되든 최근 ~3개월에 걸쳐 고르게 분포한다 — Dashboard 캘린더의 점/하이라이트가 항상 의미 있게 보인다.
- **릴리즈 격리**: `DebugSeeder`는 `debug`/`release` 소스셋에 각각 다른 구현(디버그=실제 시딩, 릴리즈=no-op)으로 존재한다(Kotlin 소스셋은 variant별로 합산되는 방식이라 `main`에는 두지 않음 — 자세한 이유는 `DebugSeeder.kt` 주석 참고). `app/src/debug/assets/`도 debug 전용이라 릴리즈 APK에는 이미지가 전혀 포함되지 않는다. `./gradlew :app:assembleRelease`로 검증 완료.
